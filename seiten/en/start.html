Quick start

Four steps and it runs. No installation, no accounts.

  1. Download

    Put KERS_Subsystems.exe into a folder of its own — the button above downloads it directly. No installation. On the first start a folder data\ appears next to it — that is where your settings, window position, championship standings, own layouts, the circuit outlines you drove and the recordings live.

  2. Switch telemetry on

    In the game under Settings → Telemetry:

    UDP TelemetryOn
    UDP Format2026
    IP127.0.0.1
    Port20777
    Player namesOn

    Racing with others: every driver sets this for themselves. For names instead of placeholders to show in the overlay, the others in the lobby need player names set to On as well. Anyone who also switches their telemetry from restricted to public supplies what onboard and the tyre display need — not required, the overlay runs without it.

  3. Start

    Open the EXE — control panel, HUD and server come up together. Nothing to press.

    On the first start the Windows firewall asks whether the program may be reached on the network. For the control page and settings from your phone or a second PC, allow private networks — on the PC itself it works without.

    Open the EXE — the KERS Subsystems control panel appears. Press Start Server there, then HUD IS ON.

    From 0.3.0 that goes away: control panel, HUD and server then come up together. What else 0.3.0 brings

  4. Set up

    Two pages in the browser — one button each on the control panel, or opened directly once the server runs:

    /regieThe whole field, camera hint, camera control and the cut-ins
    /settingsBranding, colours, opacity, visibility, layout

    The overlay itself is not opened in a browser — it runs in the HUD window and, for recording, in the OBS window.

Self-update. On start the program quietly checks whether a newer version exists. The download is verified against size and SHA-256 before it replaces the running file — the old one stays behind as a fallback until the new one has started once. A specific version can be picked on the control panel.
Already on 0.2.x? Then the update button takes you to 0.3.0 as usual. Settings, championship standings and window position stay; the new file clears away the old one on its first start. Going back to a 0.2.x works the same way on the control panel.
