Schnellstart

Vier Schritte, dann läuft es. Keine Installation, keine Konten.

  1. Herunterladen

    Die KERS_Subsystems.exe in einen eigenen Ordner legen — der Knopf oben lädt sie direkt. Keine Installation. Beim ersten Start entsteht daneben ein Ordner data\ — dort liegen deine Einstellungen, Fensterlage, WM-Stände, eigenen Layouts, die selbst gefahrenen Streckenkonturen und die Aufzeichnungen.

  2. Telemetrie einschalten

    Im Spiel unter Einstellungen → Telemetrie:

    UDP TelemetryAn
    UDP Format2026
    IP127.0.0.1
    Port20777
    SpielernamenAn

    Im Rennen mit anderen: Diese Einstellungen macht jeder Fahrer für sich. Damit im Overlay Namen statt Platzhalter stehen, muss auch bei den anderen in der Lobby Spielernamen auf An stehen. Wer seine Telemetrie zusätzlich von Eingeschränkt auf Öffentlich stellt, liefert auch das, was Onboard und Reifenanzeige brauchen — nötig ist das nicht, das Overlay läuft auch ohne.

  3. Starten

    EXE öffnen — es erscheint das Schaltbrett KERS Subsystems. Dort Start Server drücken, dann HUD IST AN.

  4. Einrichten

    Zwei Seiten im Browser — im Schaltbrett je ein Knopf, oder direkt aufgerufen, sobald der Server läuft:

    /regieDas ganze Feld, Kamera-Tipp, Kamera setzen und die Einblendungen
    /settingsBranding, Farben, Deckkraft, Sichtbarkeit, Layout

    Das Overlay selbst wird nicht im Browser aufgerufen — es läuft im HUD-Fenster und für die Aufnahme im OBS-Fenster.

Selbst-Update. Beim Start sieht das Programm still nach, ob es eine neuere Fassung gibt. Der Download wird gegen Größe und SHA-256 geprüft, bevor er die laufende Datei ersetzt — die alte bleibt als Rückfallebene liegen. Eine bestimmte Fassung wählst du im Schaltbrett gezielt aus.
