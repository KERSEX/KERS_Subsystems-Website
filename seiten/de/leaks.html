Version 0.3.0

Neu gebaut. In C++.

Server und Overlay werden ein einziges Programm aus C++ und Qt 6. Kein Python, kein Chromium, kein zweites Programm im Hintergrund — und eine EXE, die nur noch ein Viertel so groß ist.

  • Stand im Test
  • Kommt als Update über den Knopf im Schaltbrett
  • Quellcode Zweig cpp-0.3.0 ↗

Was sich für dich ändert

  • Startet komplett. EXE öffnen — Schaltbrett, HUD und Server gehen zusammen auf. Wer den Server nicht will, startet mit --no-server.
  • Eine Frage beim ersten Start. Die Windows-Firewall fragt nach dem Netzwerk. Für Regie und Settings vom Handy Private Netzwerke erlauben.
  • Kein Konsolenfenster mehr. Was Server und HUD melden, steht unter Log im Schaltbrett und in data\kers.log.
  • Kein Browser geht von selbst auf. Regie und Settings öffnest du über die Knöpfe im Schaltbrett.
  • Eine Darstellung. Die Renderer-Auswahl fällt weg — das HUD ist die QML-Szene, dieselbe wie bisher.
  • Trackmap bleibt stehen. Nach dem Wechsel von der Quali ins Rennen ist die Karte einer bekannten Strecke sofort da.
  • Ein Programm pro Port. Läuft noch eine alte 0.2.x, meldet das Schaltbrett Port belegt, statt dass sich zwei die Pakete teilen.
  • Deine Daten bleiben. Einstellungen, WM-Stände und Fensterlage aus 0.2.x laufen unverändert weiter. Zurück auf 0.2.x geht über das Schaltbrett.
