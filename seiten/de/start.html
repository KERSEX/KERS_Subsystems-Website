Schnellstart

Vier Schritte, dann läuft es. Keine Installation, keine Konten.

  1. Herunterladen

    Die KERS_Subsystems.exe in einen eigenen Ordner legen — der Knopf oben lädt sie direkt. Keine Installation. Beim ersten Start entsteht daneben ein Ordner data\ — dort liegen deine Einstellungen, Fensterlage, WM-Stände, eigenen Layouts, die selbst gefahrenen Streckenkonturen und die Aufzeichnungen.

  2. Telemetrie einschalten

    Im Spiel unter Einstellungen → Telemetrie:

    UDP TelemetryAn
    UDP Format2026
    IP127.0.0.1
    Port20777
    SpielernamenAn

    Im Rennen mit anderen: Diese Einstellungen macht jeder Fahrer für sich. Damit im Overlay Namen statt Platzhalter stehen, muss auch bei den anderen in der Lobby Spielernamen auf An stehen. Wer seine Telemetrie zusätzlich von Eingeschränkt auf Öffentlich stellt, liefert auch das, was Onboard und Reifenanzeige brauchen — nötig ist das nicht, das Overlay läuft auch ohne.

  3. Starten

    EXE öffnen — Schaltbrett, HUD und Server gehen zusammen auf. Nichts zu drücken.

    Beim ersten Start fragt die Windows-Firewall, ob das Programm im Netzwerk erreichbar sein darf. Für Regie und Settings vom Handy oder zweiten PC Private Netzwerke erlauben — nur am eigenen Rechner geht es auch ohne.

  4. Einrichten

    Zwei Seiten im Browser — im Schaltbrett je ein Knopf, oder direkt aufgerufen, sobald der Server läuft:

    /regieDas ganze Feld, Kamera-Tipp, Kamera setzen, die Einblendungen und OBS
    /settingsDesign, Branding, Farben, Deckkraft, Sichtbarkeit, Layout, WM-Punkte, OBS

    Vom Handy, Tablet oder zweiten PC fragt die Seite beim ersten Aufruf nach einem Code — er steht im Schaltbrett unter Zugriff. Einmal eingegeben, bleibt das Gerät freigegeben.

    Das Overlay selbst wird nicht im Browser aufgerufen — es läuft im HUD-Fenster und für die Aufnahme im OBS-Fenster.

Selbst-Update. Beim Start sieht das Programm still nach, ob es eine neuere Version gibt. Der Download wird gegen Größe und SHA-256 geprüft, bevor er die laufende Datei ersetzt — die alte bleibt als Rückfallebene liegen, bis die neue einmal gestartet ist. Eine bestimmte Version wählst du im Schaltbrett gezielt aus.
Schon 0.2.x im Einsatz? Dann bringt dich der Update-Knopf ganz normal auf 0.3.0. Einstellungen, WM-Stände und Fensterlage bleiben, die alte Datei räumt die neue beim ersten Start selbst weg. Zurück auf eine 0.2.x geht im Schaltbrett genauso.
