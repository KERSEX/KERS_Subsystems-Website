Technik & Hilfe

Was unter der Haube läuft, und was hilft, wenn es klemmt.

F1 26UDP · Port 20777
Parser + Flaskmain.py · Port 5100
HUD-Fensterdurchsichtig, immer oben
OBS-Fensterdeckend, Canvas-Größe
Spiel
F1 26, UDP-Format „2026". Ältere Titel senden ein anderes Format und werden nicht gelesen.
Ports
5100 Weboberfläche · 20777 Telemetrie
Renderer
Die QML-Szene. Die alten HTML-Seiten liegen als Rückfallebene daneben, die OBS-Schalter gelten aber nur für QML.
Renderrate
10 bis 120 Hz. Das Spiel sendet höchstens 60 Pakete/s; darüber laufen nur noch die weichen Zähler flüssiger.
Quellcode
Python 3.13, Flask und PySide6. run.bat legt die venv an und startet den Server, start_hud.bat das Desktop-HUD.
Deine Daten
Alles Persönliche liegt in data\ neben der EXE. Die EXE selbst enthält keine.
Es kommt nichts an.

Die Statuszeile im Schaltbrett zeigt getrennt an, ob der Server läuft und ob UDP-Pakete ankommen. Sendet das Spiel ein anderes Format als 2026, kommen zwar Pakete an, werden aber nicht gelesen. Beim Testen darf außerdem nur eine Quelle auf Port 20777 senden — entweder das Spiel oder ein Testsender, sonst mischen sich die Daten.

Das HUD liegt hinter dem Spiel.

Im randlosen Vollbild schiebt sich das Spiel manchmal nach vorn. Das HUD meldet sich alle zwei Sekunden von selbst wieder oben an. Hilft das nicht, läuft das Spiel meist im echten Vollbild — fürs Bild im Stream ist ohnehin das OBS-Fenster zuständig, und das läuft davon unberührt weiter.

OBS findet das Fenster nicht.

Gesucht ist [KERS_Subsystems]: KERS OBS — nicht das HUD-Fenster. Willst du doch das HUD selbst aufnehmen, muss In OBS auffindbar im Schaltbrett an: das HUD läuft sonst als Werkzeugfenster, und genau die wirft OBS aus seiner Liste. Der Preis ist ein Eintrag in der Taskleiste — beides hängt an derselben Eigenschaft.

Ich bekomme das HUD nicht mit der Maus zu fassen.

Ab Werk ist es gesperrt — genau das lässt die Klicks zum Spiel durch. Zum Verschieben erst im Schaltbrett oder über das Symbol im Infobereich entsperren.

Das Overlay sieht anders aus als erwartet.

Beim Start aus dem Quellcode müssen die Schriften einmalig erzeugt werden: python tools\woff2_to_ttf.py. Qt kann keine woff2-Dateien lesen und fällt sonst auf die Systemschrift zurück.

Alles Weitere steht in der README des Projekts und in den Technik-Notizen zum HUD.
